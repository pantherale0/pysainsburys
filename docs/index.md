# Sainsburys API

A async integration API for Sainsburys

## Features

- Async-first integration layer for hardware and software systems
- **http** transport via aiohttp
- Python 3.10+ support
- Tested with pytest and GitHub Actions
- Packaging with [uv](https://docs.astral.sh/uv/)
- Linting and formatting with [Ruff](https://docs.astral.sh/ruff/)
- Documentation built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/)
