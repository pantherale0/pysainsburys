# Installation

Install Sainsburys API from PyPI:

```bash
pip install pysainsburys
```

Or with [uv](https://docs.astral.sh/uv/):

```bash
uv add pysainsburys
```

## Development Installation

Clone the repository and install in editable mode:

```bash
git clone https://github.com/pantherale0/pysainsburys.git
cd pysainsburys
uv sync
```
